# bshes740_assignment1_taylor

## BSHES 740 Assignment 1

This project contains the workflow to complete Assignment 1 for BSHES 740 in the Fall 2026 semester.

This repository allows us to share the code involved in this project.

## Structure

* `analysis/` contains the source Quarto Markdown files that answer the questions in this assignment.
* `data/` contains the 2 datasets for this assignment.
* `drafts/` contains submission paper drafts.
* `literature/` contains the assignment document.
* `results/` contains results exported by the analysis files.
